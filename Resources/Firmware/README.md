# Felucca 1.7.0

`felucca-1.7.0.fwsc` is [Felucca](https://github.com/hugelton/Felucca) by hugelton, an FM-1
firmware, unchanged from its [v1.7.0 release](https://github.com/hugelton/Felucca/releases/tag/v1.7.0).
It is licensed under the GNU GPL v3 (`LICENSE-Felucca.txt`); its source is in that repository.
The iOS app carries it as a separate program that the emulator runs; it is not part of this
repository's MIT-licensed code.
